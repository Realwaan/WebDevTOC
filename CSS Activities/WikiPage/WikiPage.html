Overview

Welcome to the 3D Web Experience Wiki, a collection of pages documenting the technologies used for rendering three-dimensional graphics in web browsers. The articles here cover everything from the low-level WebGL API to higher-level libraries like Three.js and React Three Fiber.

Over the past several years, browser support for hardware-accelerated graphics has matured significantly. What used to require Flash or Java applets now runs natively in every major browser through WebGL. This shift opened the door for a whole ecosystem of tools, frameworks, and workflows that make 3D content on the web practical for production use.

Getting started

If you are new to 3D on the web, the choice of tool depends mostly on your project requirements and existing tech stack. Here is a rough guide:

  • If you want something visual with minimal coding, try Spline.
  • If you are already using React, React Three Fiber will feel natural.
  • For full control without a framework, Three.js on its own is the standard choice.
  • Raw WebGL is mainly relevant when building custom rendering engines or writing shader-heavy effects.
