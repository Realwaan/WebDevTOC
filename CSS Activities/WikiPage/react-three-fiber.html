About

React Three Fiber (often abbreviated R3F) is a React renderer for Three.js. Rather than calling Three.js imperatively with new THREE.Mesh(), R3F lets you describe 3D scenes using JSX — the same syntax you already know from building React UIs.

It is maintained by the Poimandres (Pmndrs) open-source collective. Despite what the declarative syntax might suggest, R3F does not simplify or limit Three.js in any way. Every Three.js class is available as a JSX element, and you still have full access to the underlying objects through refs.

How it works

R3F provides a <Canvas> component that sets up a Three.js scene, camera, and WebGL renderer automatically. Inside this canvas, standard Three.js objects like meshes, lights, and groups become React components. State changes trigger re-renders just like any other React component, and the library handles all the synchronization with Three.js internally.

The useFrame hook gives you access to the animation loop — it fires on every frame and is where you put any per-frame logic like rotations or physics updates.

Key components and hooks

NameTypePurpose
<Canvas>ComponentRoot container, creates the scene and renderer
<mesh>Component3D object composed of geometry + material
useFrame()HookRuns callback on every render frame
useThree()HookAccess the scene, camera, and renderer
useLoader()HookLoad assets like textures or models

Usage example

Spinning box with standard material:

import { Canvas, useFrame } from '@react-three/fiber';
import { useRef } from 'react';

function Box() {
  const mesh = useRef();

  useFrame(() => {
    mesh.current.rotation.x += 0.01;
    mesh.current.rotation.y += 0.01;
  });

  return (
    <mesh ref={mesh}>
      <boxGeometry args={[1, 1, 1]} />
      <meshStandardMaterial color="#2194ce" />
    </mesh>
  );
}

export default function App() {
  return (
    <Canvas>
      <ambientLight intensity={0.5} />
      <directionalLight position={[5, 5, 5]} />
      <Box />
    </Canvas>
  );
}

Drei helper library

@react-three/drei is a companion library that provides commonly needed components so you don't have to build them yourself:

OrbitControlsMouse and touch camera orbit controls
useGLTFLoads and caches .glb / .gltf models
EnvironmentHDR environment maps for lighting
Text3D text rendering using SDF fonts
ScrollControlsTies the scene to page scroll position

Scroll-driven animation

One of the more impressive things you can do with R3F is tie 3D transformations directly to scroll position. The ScrollControls and useScroll components from drei make this straightforward: 

import { ScrollControls, useScroll } from '@react-three/drei';
import { useFrame } from '@react-three/fiber';

function RotatingModel() {
  const scroll = useScroll();
  const ref = useRef();

  useFrame(() => {
    ref.current.rotation.y = scroll.offset * Math.PI * 2;
  });

  return <mesh ref={ref}>...</mesh>;
}

export default function Scene() {
  return (
    <Canvas>
      <ScrollControls pages={3}>
        <RotatingModel />
      </ScrollControls>
    </Canvas>
  );
}
