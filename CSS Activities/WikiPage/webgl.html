About

WebGL (Web Graphics Library) is a JavaScript API for rendering 2D and 3D graphics in the browser through the HTML <canvas> element. It is based on OpenGL ES 2.0 and gives web pages direct access to the GPU without requiring any plugins.

Nearly every 3D library for the web — Three.js, React Three Fiber, Babylon.js — compiles down to WebGL calls under the hood. Most developers never interact with WebGL directly because the API is extremely verbose; even drawing a single colored triangle takes dozens of lines of code. That said, understanding what WebGL does is useful context for working with any of the libraries that sit on top of it.

Rendering pipeline

Data flows from JavaScript (running on the CPU) to shader programs (running on the GPU):

JavaScript (CPU side)
  1. Define vertex data as typed arrays (Float32Array)
  2. Upload data to GPU memory via buffer objects
  3. Compile vertex + fragment shaders from GLSL source
  4. Set uniform variables (matrices, colors, textures)

GPU pipeline
  5. Vertex shader runs once per vertex (positioning)
  6. Rasterizer fills triangles with fragments
  7. Fragment shader runs once per pixel (coloring)
  8. Output goes to the framebuffer (canvas)

Shaders

Shaders are small programs written in GLSL (OpenGL Shading Language) that execute on the GPU. WebGL requires at least two shaders to draw anything:

Vertex shader

Runs once per vertex. Transforms 3D coordinates into screen positions.

attribute vec4 a_position;
uniform mat4 u_matrix;

void main() {
  gl_Position = u_matrix * a_position;
}

Fragment shader

Runs once per pixel. Determines the color of each fragment.

precision mediump float;
uniform vec4 u_color;

void main() {
  gl_FragColor = u_color;
}

WebGL 2.0

WebGL 2.0, based on OpenGL ES 3.0, adds several capabilities over the original 1.0 spec:

  • Instanced rendering for drawing many copies of the same geometry efficiently
  • Multiple render targets
  • Uniform buffer objects
  • Transform feedback for GPU-side particle systems
  • Better texture formats and compression support
