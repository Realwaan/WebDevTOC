About

Spline is a browser-based 3D design tool that lets you create interactive scenes for the web without writing code. The interface is similar to tools like Figma, but works in three dimensions — you add shapes, apply materials, set up lighting, and define interactions all through a visual editor.

Spline is primarily aimed at designers and teams who want to add 3D elements to websites quickly. For projects that need custom shaders or complex logic, a code-based approach with Three.js or React Three Fiber is usually more appropriate.

Editor workflow

The general process for creating something in Spline looks like this:

  1. Scene setup — Add primitives (cubes, spheres, custom shapes, text) and position them in 3D space using drag handles.
  2. Materials — Apply colors, gradients, glass and metallic presets, or environment maps through the side panel.
  3. Animation — Define states and transitions triggered by hover, click, or scroll events. Also supports keyframe animation for more complex motion.
  4. Export — Publish as a link, embed via iframe, export as a React component, or download a .splinecode file for self-hosting.

Embedding in websites

There are a few ways to get a Spline scene into a web page:

React component

import Spline from '@splinetool/react-spline';

export default function Scene() {
  return (
    <Spline scene="https://prod.spline.design/xxx/scene.splinecode" />
  );
}

Vanilla JavaScript

import { Application } from '@splinetool/runtime';

const canvas = document.getElementById('canvas3d');
const app = new Application(canvas);
app.load('https://prod.spline.design/xxx/scene.splinecode');

Iframe

The simplest option — no npm install needed, just paste the embed URL:

<iframe src="https://my.spline.design/xxx"
        width="100%" height="500"
        frameborder="0"></iframe>

CollaborationReal-time multiplayer editing
Export optionsReact, vanilla JS, iframe, downloadable file

Limitations

There are some trade-offs to be aware of:

  • No custom shader support — you are limited to the built-in material options
  • The Spline runtime adds some weight to page load
  • Scenes are tied to Spline's ecosystem (hosting or runtime)
  • Complex scenes can perform poorly on mobile devices
  • Some features require a paid subscription
