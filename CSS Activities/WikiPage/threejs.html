About

Three.js is an open-source JavaScript library for creating 3D graphics that run in web browsers using WebGL. It wraps the verbose, low-level WebGL API into something that is actually practical to work with, handling scene graphs, cameras, materials, and render loops so you don't have to write all of that from scratch.

It is by far the most popular library for 3D on the web. Most frameworks and tools in this space, including React Three Fiber, are built on top of it.

History

Three.js was created by Ricardo Cabello, known online as "Mr.doob," and first released in 2010. It started as an experiment porting a Processing sketch to JavaScript and grew into the de facto standard for browser-based 3D rendering. The library is MIT-licensed and actively maintained on GitHub with regular monthly releases.

Core concepts

Scene

The Scene acts as a container for everything: meshes, lights, cameras, helpers. You add objects to the scene and the renderer draws whatever the camera can see. Think of it as the stage in a theater production.

Camera

The most commonly used camera type is PerspectiveCamera, which simulates how the human eye perceives depth. You set a field of view (typically 50-75 degrees), aspect ratio, and near/far clipping planes. There is also OrthographicCamera for isometric or top-down views.

Renderer

WebGLRenderer takes a scene and a camera and draws the result onto an HTML canvas element. Through the renderer you can control resolution, antialiasing, shadow maps, tone mapping, and output color space.

Geometry and materials

A Mesh is just a geometry (shape defined by vertices) combined with a material (how the surface looks). Three.js ships with basic geometries like BoxGeometry, SphereGeometry, and PlaneGeometry. For materials, MeshStandardMaterial is the go-to for physically based rendering, while MeshBasicMaterial is useful when you need flat, unlit surfaces.

Example code

A minimal rotating cube:

import * as THREE from 'three';

const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(
  75, window.innerWidth / window.innerHeight, 0.1, 1000
);
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
document.body.appendChild(renderer.domElement);

const geometry = new THREE.BoxGeometry(1, 1, 1);
const material = new THREE.MeshStandardMaterial({ color: 0x2194ce });
const cube = new THREE.Mesh(geometry, material);
scene.add(cube);

const light = new THREE.DirectionalLight(0xffffff, 1);
light.position.set(5, 5, 5);
scene.add(light);

camera.position.z = 3;

function animate() {
  requestAnimationFrame(animate);
  cube.rotation.x += 0.01;
  cube.rotation.y += 0.01;
  renderer.render(scene, camera);
}
animate();
